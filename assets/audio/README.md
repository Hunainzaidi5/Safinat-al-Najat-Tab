# Ziyarat-e-Ashura Audio File

Place your audio file here with the exact filename:

    ziyarat_ashura.mp3

## Requirements
- Format: MP3 (recommended) or any browser-supported audio format
- Duration: The bundled `ziyarat_ashura.json` timestamps target ~40 minutes (2400 seconds)
  Adjust `startTime`/`endTime` in the JSON to match your specific recording.

## How to update timestamps
Open `assets/data/ziyarat_ashura.json` and edit `startTime` / `endTime` (in seconds)
for each paragraph to match the timestamp in your audio file.

## File too large?
Chrome Web Store limit is 128 MB. A typical Ziyarat recitation at 128 kbps is ~40 MB,
well within limits. If your file is larger, convert to 96 kbps MP3.
